# hs-smart-apply

`hs-smart-apply` preprocesses herdr-spreader YAML layouts, expanding scoped
variables and combining inherited `commands:` lists for each pane.

Install it with pip from a local checkout or directly from GitHub, then run the
`hs-smart-apply` command with a layout file.
